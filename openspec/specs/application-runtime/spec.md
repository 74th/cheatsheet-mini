# Application Runtime Specification

## Purpose

個人のローカルMarkdownから必要なセクションを数秒以内に参照するため、macOS上で軽量に常駐し、検索への入口を提供する。

## Requirements

### Requirement: macOSメニューバー常駐
アプリはmacOS上のネイティブなメニューバー常駐アプリとして動作し、通常はDockに表示されない構成とする SHALL。現在の対象環境はmacOS 13以上で、Swift / SwiftUI / AppKitを使用する。

#### Scenario: 通常の起動
- **WHEN** アプリを起動する
- **THEN** メニューバーから操作でき、通常のDockアイコンを表示せず常駐する

### Requirement: メニューバー操作
アプリはメニューバーから検索パネルの呼び出し、手動インデックス更新、設定画面の表示、終了を提供する SHALL。メニューには検索対象フォルダを直接選択する項目を表示せず、フォルダ変更は設定画面から行う。メニューの表示文言は固定しない。

#### Scenario: メニューから検索する
- **WHEN** メニューバーで検索を開く操作を選ぶ
- **THEN** 検索パネルを呼び出せる

#### Scenario: 常駐を終了する
- **WHEN** メニューバーで終了を選ぶ
- **THEN** アプリが終了する

#### Scenario: 設定を開く
- **WHEN** メニューバーで設定を開く操作を選ぶ
- **THEN** 検索対象フォルダのパスとショートカットを変更できる設定画面が前面に表示される

#### Scenario: メニューの操作一覧を確認する
- **WHEN** ステータスバーメニューを開く
- **THEN** 検索、設定、手動インデックス更新、終了の操作が表示され、フォルダを直接選択する項目は表示されない

#### Scenario: メニューから手動更新する
- **WHEN** メニューバーで手動インデックス更新を選ぶ
- **THEN** 現在の検索対象フォルダのインデックスを手動更新する

### Requirement: ローカル中心の参照専用動作
アプリはローカルMarkdownの参照とメモリ内検索をネットワーク接続やデータベースなしで提供する SHALL。Markdownの作成・編集、本文全文検索、SQLite/FTS、外部検索エンジン、Dash docset互換、オンライン文書取得、クラウド同期、タグ管理、AI・ベクトル検索は初期仕様の対象外とする。依存取得を伴う初回ビルドと、文書自身に含まれる外部リソースのロードはローカル検索の要件と区別する。

#### Scenario: オフラインで参照する
- **WHEN** インデックス構築済みのローカル文書をネットワーク未接続で検索する
- **THEN** 候補とローカル本文を参照でき、検索のために外部サービスやDBを必要としない

### Requirement: 検索速度の優先
アプリは約200ファイルを想定し、インデックス構築後の候補検索をメモリ上で行う SHALL。入力から候補更新まで50ms未満を性能目標とし、厳密なリアルタイム保証とはしない。設定済みショートカットから表示・入力可能になるまでの体感速度を最優先し、キーボード操作、本文・コード・画像の可読性、更新安定性、見た目の順に品質を優先する。

#### Scenario: 構築済みインデックスを検索する
- **WHEN** 約200ファイルのインデックスに対して検索文字を入力する
- **THEN** 候補検索は原則ディスクアクセスなしで行われ、人間が遅延を感じない速度を目標とする
- **AND** Markdownプレビューに必要なローカル画像読み込みは候補検索とは区別する
