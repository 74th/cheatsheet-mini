# Directory Settings Specification

## Purpose

既存のMarkdownファイルをそのまま利用できるように、検索対象フォルダの選択と次回起動時の復元を提供する。

## Requirements

### Requirement: 検索対象フォルダの選択
アプリはNSOpenPanelでMarkdownファイルを保存したフォルダをユーザーが指定できるようにする SHALL。初回起動など未設定時に選択できる。通常のフォルダ変更は設定画面から行い、メニューバーと検索パネル下部には直接のフォルダ選択操作を表示しない。設定画面では検索対象フォルダのパスを表示し、パス入力またはフォルダ選択で変更・適用できるようにする。対象は一つのフォルダであり、個別Markdownファイルの指定ではない。

#### Scenario: 初回起動
- **WHEN** 検索対象フォルダが未設定でアプリを起動する
- **THEN** ユーザーがフォルダを選択できる

#### Scenario: 対象フォルダを変更する
- **WHEN** メニューバーまたは検索パネル右下から設定画面を開き、別のフォルダを指定して適用する
- **THEN** 以後のインデックスと検索は新しいフォルダを対象とする

#### Scenario: 設定画面でパスを入力する
- **WHEN** 設定画面で読み取り可能なフォルダの絶対パスを入力して適用する
- **THEN** 検索対象をそのフォルダへ変更し、直下のMarkdownからインデックスを再構築する
- **AND** 設定画面のパス表示も新しいフォルダに一致する

#### Scenario: 設定画面でフォルダを選択する
- **WHEN** 設定画面の選択操作で別のフォルダを選び、適用する
- **THEN** パス入力と同じ保存・対象変更を行う

### Requirement: フォルダ設定の永続化
アプリは選択したフォルダを次回起動時に再利用できるよう保存する SHALL。アクセス継続に必要な場合はSecurity-Scoped Bookmarkを保存・復元する。設定画面で適用したフォルダにも同じ保存・復元を行い、更新前に保存したフォルダ設定を引き継ぐ。インデックス自体の永続化は必要とせず、ウィンドウサイズ等のUI設定の保存も必須とはしない。

#### Scenario: 次回起動で復元する
- **WHEN** フォルダを選択して終了した後、アプリを再起動する
- **THEN** 保存したフォルダを対象として起動時のインデックスを構築する

#### Scenario: 設定画面で保存したパスを復元する
- **WHEN** 設定画面でフォルダを適用した後に再起動する
- **THEN** 同じフォルダを対象とし、設定画面にも復元したパスを表示する

#### Scenario: 既存バージョンから更新する
- **WHEN** 既存のフォルダ設定が保存された状態で更新版を起動する
- **THEN** そのフォルダを引き継ぎ、再選択を要求しない

### Requirement: 非再帰のファイル対象
アプリは指定フォルダ直下のMarkdownファイルのみをインデックス化する SHALL。サブディレクトリを再帰探索しない。画像等の参照リソースは検索エントリとして取り込まない。

#### Scenario: サブディレクトリを含むフォルダ
- **WHEN** 指定フォルダに `sbx.md` と `old/legacy.md` が存在する
- **THEN** `sbx.md` をインデックス対象とし、`old/legacy.md` を対象にしない

#### Scenario: Markdown以外のファイル
- **WHEN** 指定フォルダにMarkdownと画像ファイルが存在する
- **THEN** Markdownを検索対象とし、画像ファイル自体は検索エントリにしない

### Requirement: フォルダパスの検証
アプリは設定画面でフォルダ変更を適用する前に、存在する読み取り可能なフォルダであり保存可能であることを検証する SHALL。無効な入力や保存失敗時は理由を表示し、以前のフォルダ設定とインデックスを維持する。空入力による設定解除は提供しない。

#### Scenario: 無効なパスを適用する
- **WHEN** 空文字、存在しないパス、個別ファイル、または読み取り不能なフォルダを適用する
- **THEN** エラーを表示し、以前のフォルダ・保存値・インデックスを維持する

#### Scenario: フォルダ設定が保存できない
- **WHEN** 新しいフォルダの永続化に必要な情報を生成・保存できない
- **THEN** 適用失敗を表示し、以前の対象フォルダで検索を続けられる
